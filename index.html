FAQ

Quick answers for builders joining DevShowcase.

Can I showcase a GitHub project?

Yes. Sign in with GitHub and submit a repository. Submissions can be reviewed before appearing publicly.

Can I find collaborators?

Yes. Use discussions, member profiles, opportunities, events and project pages to discover collaboration paths.

Is the platform open source?

The DevShowcase repository is maintained as an open-source project with contribution and security guidance.
